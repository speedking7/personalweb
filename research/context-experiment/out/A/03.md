基于现有代码结构(frontmatter 解析器 `parseBlogMetadata` 被飞书和本地两条数据源共用,`resolveCover` 处理本地图片的部署前缀),给出以下实现方案。

> 说明:我没有拿到 `pages/Blog.tsx` 等页面文件的实际源码(工具权限未开放,文件读取工具在本次会话不可用),分组渲染那部分给出的是可直接套用的组件,接入点需要你按实际页面结构挂载一下。

## 1. `app/src/types/blog.ts` —— 加 `series` 字段

```ts
export interface BlogPost {
  id: string;
  title: string;
  excerpt: string;
  content: string;
  coverImage: string;
  category: string;
  tags: string[];
  date: string;
  readTime: number;
  series?: string; // 系列名,如 "AI 转型指南";不属于任何系列则不写
}
```

## 2. `app/src/lib/markdown.ts` —— 解析 `series` frontmatter

在 `tagsMatch` 附近加一行提取逻辑(不设默认值,未命中就是 `undefined`,和现有字段未命中不覆盖默认值的规则一致):

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();
```

放在 `dateMatch` 和 `coverMatch` 之间即可,不影响后面的默认值填充块。

## 3. 新建 `app/src/content/series.ts` —— 系列封面注册表

系列封面是本地静态资源,飞书文章的 frontmatter 只带 `series` 这个名字字符串,不会带封面图,所以封面必须单独登记,和文章数据源无关:

```ts
/**
 * 系列封面注册表:系列名 -> 本地封面图路径
 * frontmatter 里的 series 只是名字,封面不随文章走(飞书文章同样只有名字没有封面)。
 * 新增系列 = 这里加一条 + 把封面图放进 content/covers/series/
 */
export interface SeriesMeta {
  name: string;
  cover: string; // 相对路径,如 covers/series/xxx.svg
  description?: string;
}

export const seriesRegistry: SeriesMeta[] = [
  {
    name: 'AI 转型指南',
    cover: 'covers/series/ai-transformation.svg',
    description: '从传统开发到 AI 驱动开发的转型系列',
  },
];
```

图片实际放在 `app/src/content/covers/series/ai-transformation.svg`(和现有文章封面同目录风格)。

## 4. `app/src/data/blogs.ts` —— 分组聚合逻辑

在文件里加 import 和新导出函数,复用已有的 `resolveCover`:

```ts
import { seriesRegistry, type SeriesMeta } from '@/content/series';

export interface SeriesGroup {
  name: string;
  cover: string;
  description?: string;
  posts: BlogPost[];
}

// 封面同样要过部署 base 前缀处理,复用现有 resolveCover
const resolvedSeriesRegistry: SeriesMeta[] = seriesRegistry.map(s => ({
  ...s,
  cover: resolveCover(s.cover),
}));

function findSeriesMeta(name: string): SeriesMeta {
  return (
    resolvedSeriesRegistry.find(s => s.name === name) ?? { name, cover: '' }
  ); // 未登记封面时留空,交给组件兜底样式,而不是报错
}

/**
 * 按系列分组;没有 series 字段的文章不进入任何分组
 */
export async function getPostsBySeries(): Promise<SeriesGroup[]> {
  const posts = await getBlogPosts();
  const groups = new Map<string, BlogPost[]>();

  posts.forEach(post => {
    if (!post.series) return;
    const list = groups.get(post.series) ?? [];
    list.push(post);
    groups.set(post.series, list);
  });

  return Array.from(groups.entries()).map(([name, seriesPosts]) => {
    const meta = findSeriesMeta(name);
    return {
      name,
      cover: meta.cover,
      description: meta.description,
      // 系列内按时间正序,体现阅读顺序;区别于列表页整体的倒序(最新优先)
      posts: seriesPosts.sort((a, b) => a.date.localeCompare(b.date)),
    };
  });
}
```

注意事项:`series` 匹配是按 frontmatter 字符串和 registry 里的 `name` 精确相等来查封面,这和现有 `category` 处理成自由字符串(不设注册表)的做法不同——因为 category 不需要独立配图,series 需要。写文章时 `series: AI 转型指南` 要和 `series.ts` 里的名字完全一致,否则该系列显示时封面为空。

## 5. 新建 `app/src/components/SeriesGroup.tsx` —— 分组展示组件

```tsx
import type { BlogPost } from '@/types/blog';

interface SeriesGroupProps {
  name: string;
  cover: string;
  description?: string;
  posts: BlogPost[];
}

export function SeriesGroup({ name, cover, description, posts }: SeriesGroupProps) {
  return (
    <section className="series-group">
      <div className="series-header">
        {cover ? (
          <img src={cover} alt={name} className="series-cover" />
        ) : (
          <div className="series-cover series-cover--placeholder" />
        )}
        <div className="series-meta">
          <h3>{name}</h3>
          {description && <p>{description}</p>}
          <span className="series-count">{posts.length} 篇</span>
        </div>
      </div>
      <ul className="series-posts">
        {posts.map(post => (
          <li key={post.id}>
            <a href={`/blog/${post.id}`}>{post.title}</a>
          </li>
        ))}
      </ul>
    </section>
  );
}
```

## 6. 接入列表页(按 `pages/Blog.tsx` 现有数据获取模式补一段)

```tsx
import { getPostsBySeries, type SeriesGroup as SeriesGroupData } from '@/data/blogs';
import { SeriesGroup } from '@/components/SeriesGroup';

// 组件内,和现有 getBlogPosts()/getCategories() 并列拉取
const [seriesGroups, setSeriesGroups] = useState<SeriesGroupData[]>([]);
useEffect(() => {
  getPostsBySeries().then(setSeriesGroups);
}, []);

// 渲染:系列区块放在列表最上方,已归入系列的文章会重复出现在下方全量列表里,
// 因为分组只是列表页的一个视图,不改变 getBlogPosts() 的整体结果
{seriesGroups.length > 0 && (
  <div className="series-section">
    {seriesGroups.map(g => (
      <SeriesGroup key={g.name} {...g} />
    ))}
  </div>
)}
```
