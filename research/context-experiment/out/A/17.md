## 2. `app/src/lib/markdown.ts` —— 解析 `series` 字段

在 `categoryMatch` 后面加一行，**不设默认值**（不像 category 兜底成"未分类"——没写 series 的文章就应该保持无系列，否则会被错误分进一个叫 undefined 的组）：

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();
```

放在现有 `categoryMatch` 判断块之后即可,不需要动"设置默认值"那一段。

## 3. `app/src/lib/assetPath.ts`（新建）—— 抽出封面路径补全逻辑

`blogs.ts` 里已有一份 `resolveCover`（补 `BASE_URL` 前缀），系列封面要用一模一样的规则,直接复用而不是复制一份第二实现:

```ts
/**
 * [OUTPUT]: 对外提供 resolveAssetPath —— 本地相对路径补上部署 base 前缀，
 *           绝对 URL（http/https）与根路径（/ 开头）原样返回
 * [POS]: lib/ 层小工具，被文章封面（data/blogs.ts）与系列封面（data/series.ts）共用，
 *        避免"补 base"规则在两处各自实现后漂移
 * [PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
 */
export const resolveAssetPath = (path: string): string =>
  !path || /^(https?:)?\/\//.test(path) || path.startsWith('/')
    ? path
    : `${import.meta.env.BASE_URL}${path}`;
```

## 4. `app/src/data/blogs.ts` —— 改用共享函数

删掉原来内联的 `resolveCover` 定义（包括它上面的注释），改成：

```ts
import { resolveAssetPath } from '@/lib/assetPath';
```

`staticBlogPosts` 里 `coverImage: resolveCover(post.coverImage)` 改成 `coverImage: resolveAssetPath(post.coverImage)`。其余逻辑不变。

## 5. `app/src/data/series.ts`（新建）—— 系列分组的唯一入口

```ts
/**
 * [INPUT]: 依赖 @/data/blogs 的 getBlogPosts（复用同一套 feishu/static/auto 降级),
 *           @/lib/assetPath 补全系列封面路径，@/types/blog 的 SeriesInfo 契约
 * [OUTPUT]: 对外提供 groupPostsBySeries（纯函数，接收已取到的 posts）
 *           与 getSeriesList（便捷封装，内部再取一次 posts）
 * [POS]: data/ 层，"按系列分组"视图的唯一入口。系列封面独立维护在 SERIES_COVERS 里，
 *        不写进任意一篇文章的 frontmatter——封面属于系列本身而不属于某一篇文章，
 *        文章增删、改序不应牵动封面配置
 * [PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
 */
import { getBlogPosts } from './blogs';
import { resolveAssetPath } from '@/lib/assetPath';
import type { BlogPost, SeriesInfo } from '@/types/blog';

// 系列封面注册表：key 是 frontmatter 里 series 的值，value 是相对 src/content/ 的本地路径。
// 新增系列 = 把封面图放进 src/content/covers/series/，在这里登记一行。
const SERIES_COVERS: Record<string, string> = {
  'AI 转型指南': 'covers/series/ai-transformation.svg',
};

/**
 * 按系列分组；未设置 series 的文章不出现在任何分组里，由调用方决定如何展示它们
 */
export function groupPostsBySeries(posts: BlogPost[]): SeriesInfo[] {
  const order: string[] = [];
  const groups = new Map<string, BlogPost[]>();

  for (const post of posts) {
    if (!post.series) continue;
    if (!groups.has(post.series)) {
      order.push(post.series);
      groups.set(post.series, []);
    }
    groups.get(post.series)!.push(post);
  }

  return order.map(name => ({
    name,
    coverImage: resolveAssetPath(SERIES_COVERS[name] ?? ''),
    posts: groups.get(name)!.sort((a, b) => a.date.localeCompare(b.date)),
  }));
}

export async function getSeriesList(): Promise<SeriesInfo[]> {
  return groupPostsBySeries(await getBlogPosts());
}
```

`groupPostsBySeries` 是纯函数是关键：列表页本来就要调 `getBlogPosts()` 拿全部文章去渲染，分组直接复用同一份结果，不要在页面里再调 `getSeriesList()`——那会对飞书多打一次请求。`getSeriesList()` 只是给不方便拿到 posts 的场景（比如独立的系列页）用的便捷封装。

## 6. `app/src/components/blog/SeriesGroup.tsx`（新建）—— 展示组件

```tsx
import type { SeriesInfo } from '@/types/blog';

interface SeriesGroupProps {
  series: SeriesInfo;
}

export function SeriesGroup({ series }: SeriesGroupProps) {
  return (
    <section className="series-group">
      <header className="series-group__header">
        <img src={series.coverImage} alt={series.name} className="series-group__cover" />
        <div>
          <h2 className="series-group__title">{series.name}</h2>
          <span className="series-group__count">共 {series.posts.length} 篇</span>
        </div>
      </header>
      <ul className="series-group__posts">
        {series.posts.map(post => (
          <li key={post.id}>
            <a href={`/blog/${post.id}`}>{post.title}</a>
          </li>
        ))}
      </ul>
    </section>
  );
}
```

样式类名按项目现有 CSS 方案（Tailwind/CSS Module）替换即可，逻辑不变。

## 7. 接入 `app/src/pages/Blog.tsx`

在拿到 `posts` 之后（现有代码里大概率已经有一次 `getBlogPosts()` 调用）：

```tsx
import { groupPostsBySeries } from '@/data/series';
import { SeriesGroup } from '@/components/blog/SeriesGroup';

// posts 是页面已有的、await getBlogPosts() 得到的数组
const seriesList = groupPostsBySeries(posts);
const standalonePosts = posts.filter(post => !post.series);
```

渲染时先展示系列分组区，再展示原有的散篇文章列表（把原来 `posts.map(...)` 那段改成 `standalonePosts.map(...)`）：

```tsx
{seriesList.map(series => (
  <SeriesGroup key={series.name} series={series} />
))}

{/* 原有的文章列表渲染，把 posts 换成 standalonePosts */}
```
