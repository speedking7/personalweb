我会基于给出的三个文件直接给方案。由于博客列表页组件（如 `Blog.tsx`）源码未贴出，下面第 4 步用假设的文件名 `app/src/pages/Blog.tsx` 给出一份可直接套用的分组渲染逻辑，命名和现有页面组件对齐即可。

## 1. `app/src/types/blog.ts` — 加两个可选字段

```ts
export interface BlogPost {
  id: string;
  title: string;
  excerpt: string;
  content: string;
  coverImage: string;
  category: string;
  tags: string[];
  date: string;
  readTime: number;
  series?: string;       // 系列名，如 "AI 转型指南"
  seriesCover?: string;  // 系列封面，本地相对路径或飞书绝对 URL
}
```

## 2. `app/src/lib/markdown.ts` — frontmatter 新增两个正则

在现有 `coverMatch` 后面加：

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();

const seriesCoverMatch = frontmatter.match(/seriesCover:\s*["']?([^"'\n]+)["']?/);
if (seriesCoverMatch) metadata.seriesCover = seriesCoverMatch[1].trim();
```

`series`/`seriesCover` 不写默认值——没有 series 的文章就是"不属于任何系列"，不能像 `category` 那样兜底成固定字符串，否则所有文章都会被分进同一个假系列。

## 3. `app/src/data/blogs.ts` — 封面路径解析 + 分组聚合

**3a. 复用 `resolveCover` 处理 `seriesCover`**（在 `staticBlogPosts` 的 map 里）：

```ts
const staticBlogPosts: BlogPost[] = Object.entries(localPostModules)
  .map(([path, raw]) => {
    const slug = path.split('/').pop()!.replace(/\.md$/, '');
    const post = { title: slug, excerpt: '', coverImage: '', ...parseBlogMetadata(raw, slug) } as BlogPost;
    return {
      ...post,
      coverImage: resolveCover(post.coverImage),
      seriesCover: post.seriesCover ? resolveCover(post.seriesCover) : post.seriesCover,
    };
  })
  .sort((a, b) => b.date.localeCompare(a.date));
```

`resolveCover` 已经对绝对 URL 和 `/` 开头路径原样放行，所以飞书文章若把 `seriesCover` 写成完整 URL 不受影响。

**3b. 新增分组接口和函数**（追加在文件里，`clearCache` 之前即可）：

```ts
export interface SeriesGroup {
  name: string;
  cover: string;
  posts: BlogPost[];
}

/**
 * 按系列分组，组间按系列最新一篇的日期倒序，组内按日期倒序
 */
export async function getSeriesGroups(): Promise<SeriesGroup[]> {
  const posts = await getBlogPosts();
  const map = new Map<string, SeriesGroup>();

  for (const post of posts) {
    if (!post.series) continue;
    const group = map.get(post.series);
    if (group) {
      group.posts.push(post);
      if (!group.cover && post.seriesCover) group.cover = post.seriesCover;
    } else {
      map.set(post.series, { name: post.series, cover: post.seriesCover || '', posts: [post] });
    }
  }

  return Array.from(map.values())
    .map(group => ({ ...group, posts: group.posts.sort((a, b) => b.date.localeCompare(a.date)) }))
    .sort((a, b) => b.posts[0].date.localeCompare(a.posts[0].date));
}

/**
 * 不属于任何系列的文章，供列表页渲染在系列分组之外
 */
export async function getUngroupedPosts(): Promise<BlogPost[]> {
  const posts = await getBlogPosts();
  return posts.filter(post => !post.series);
}
```

**注意（飞书链路）**：如果 `feishuBlogClient.fetchBlogPosts()` 内部也是调用 `parseBlogMetadata` 生成 `BlogPost`（文件头注释暗示两条链路共用解析器），上面两处改动会自动覆盖飞书文章，无需再碰 `feishu.ts`。如果 `feishu.ts` 是自己单独抽字段拼 `BlogPost`，需要在那边同步加 `series`/`seriesCover` 的抽取，写法和 2 里的两行正则一致。

## 4. 列表页 — 按系列分组展示

假设组件在 `app/src/pages/Blog.tsx`，在现有渲染逻辑基础上改成：

```tsx
import { useEffect, useState } from 'react';
import { getSeriesGroups, getUngroupedPosts, type BlogPost, type SeriesGroup } from '@/data/blogs';

function SeriesSection({ series }: { series: SeriesGroup }) {
  return (
    <section className="mb-12">
      <div className="flex items-center gap-4 mb-4">
        {series.cover && (
          <img
            src={series.cover}
            alt={series.name}
            className="w-16 h-16 rounded-lg object-cover"
          />
        )}
        <h2 className="text-xl font-bold">{series.name}</h2>
        <span className="text-sm text-gray-500">{series.posts.length} 篇</span>
      </div>
      <div className="grid grid-cols-1 md:grid-cols-3 gap-4">
        {series.posts.map(post => (
          <BlogCard key={post.id} post={post} />
        ))}
      </div>
    </section>
  );
}

export default function Blog() {
  const [seriesGroups, setSeriesGroups] = useState<SeriesGroup[]>([]);
  const [ungrouped, setUngrouped] = useState<BlogPost[]>([]);

  useEffect(() => {
    getSeriesGroups().then(setSeriesGroups);
    getUngroupedPosts().then(setUngrouped);
  }, []);

  return (
    <div>
      {seriesGroups.map(series => (
        <SeriesSection key={series.name} series={series} />
      ))}

      {ungrouped.length > 0 && (
        <section>
          <h2 className="text-xl font-bold mb-4">其他文章</h2>
          <div className="grid grid-cols-1 md:grid-cols-3 gap-4">
            {ungrouped.map(post => (
              <BlogCard key={post.id} post={post} />
            ))}
          </div>
        </section>
      )}
    </div>
  );
}
```

`BlogCard` 沿用页面里已有的卡片组件；如果现有页面用的是分类筛选 tab 之类的交互结构，把上面两个 `section` 块接到现有筛选结果之后即可，逻辑核心是 `getSeriesGroups` / `getUngroupedPosts` 这两个数据函数。

## 5. 系列封面图片存放位置

新建目录 `app/src/content/covers/series/`，放 svg/png/jpg，和现有单篇文章封面（`content/posts/covers/x.svg`）同级模式。frontmatter 里这样引用：

```md
---
title: "转型第一步：为什么要拥抱 AI"
category: "AI"
tags: [AI, 转型]
date: "2026-01-10"
series: "AI 转型指南"
seriesCover: "covers/series/ai-transformation.svg"
readTime: 5
---
```

相对路径会走 `resolveCover`，自动补上 `import.meta.env.BASE_URL`，本地和 GitHub Pages 两边都能正确显示，无需额外处理。
