## 1. `app/src/types/blog.ts` — 扩展类型

## 2. `app/src/lib/markdown.ts` — 解析 `series`/`seriesCover`

在 `coverMatch` 附近加两个字段，两个数据源（飞书 + 本地）都走这个函数，所以不用单独改 `feishu.ts`：

```ts
const coverMatch = frontmatter.match(/cover:\s*["']?([^"'\n]+)["']?/);
if (coverMatch) metadata.coverImage = coverMatch[1].trim();

// 新增
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();

const seriesCoverMatch = frontmatter.match(/seriesCover:\s*["']?([^"'\n]+)["']?/);
if (seriesCoverMatch) metadata.seriesCover = seriesCoverMatch[1].trim();
```

不用给它们设默认值——`series` 本来就是可选字段，没写就代表这篇文章不属于任何系列。

## 3. `app/src/data/blogs.ts` — 复用 `resolveCover`，加系列聚合

`resolveCover` 目前只对本地静态文章的 `coverImage` 做 base 路径补全，`seriesCover` 也要走同一逻辑（同样会踩 GitHub Pages 的 `/personalweb/` 前缀坑）：

```ts
const staticBlogPosts: BlogPost[] = Object.entries(localPostModules)
  .map(([path, raw]) => {
    const slug = path.split('/').pop()!.replace(/\.md$/, '');
    const post = { title: slug, excerpt: '', coverImage: '', ...parseBlogMetadata(raw, slug) } as BlogPost;
    return {
      ...post,
      coverImage: resolveCover(post.coverImage),
      seriesCover: post.seriesCover ? resolveCover(post.seriesCover) : post.seriesCover,
    };
  })
  .sort((a, b) => b.date.localeCompare(a.date));
```

再加一个和 `getPostsByCategory`/`getPostsByTag` 同构的按系列筛选函数（供未来「系列详情页」用）：

```ts
export async function getPostsBySeries(series: string): Promise<BlogPost[]> {
  const posts = await getBlogPosts();
  return posts.filter(post => post.series === series);
}
```

导入类型：`import type { BlogPost, SeriesSummary } from '@/types/blog';`

## 4. 新建 `app/src/lib/series.ts` — 纯函数分组逻辑

列表页拿到的 `posts` 数组要按系列分组、非系列文章单独列出，这个逻辑不依赖网络请求，独立成纯函数避免重复 fetch：

```ts
import type { BlogPost, SeriesSummary } from '@/types/blog';

export interface SeriesGroup {
  info: SeriesSummary;
  posts: BlogPost[];
}

export function groupPostsBySeries(posts: BlogPost[]): {
  series: SeriesGroup[];
  standalone: BlogPost[];
} {
  const map = new Map<string, SeriesGroup>();
  const standalone: BlogPost[] = [];

  for (const post of posts) {
    if (!post.series) {
      standalone.push(post);
      continue;
    }
    const group = map.get(post.series);
    if (group) {
      group.posts.push(post);
      if (!group.info.coverImage && post.seriesCover) group.info.coverImage = post.seriesCover;
    } else {
      map.set(post.series, {
        info: { name: post.series, coverImage: post.seriesCover ?? '', count: 0 },
        posts: [post],
      });
    }
  }

  for (const group of map.values()) group.info.count = group.posts.length;

  return { series: Array.from(map.values()), standalone };
}
```

## 5. 新建 `app/src/components/blog/SeriesGroup.tsx` — 展示组件

```tsx
import { Link } from 'react-router-dom';
import type { SeriesGroup as SeriesGroupData } from '@/lib/series';

export function SeriesGroup({ info, posts }: SeriesGroupData) {
  return (
    <section className="series-group">
      <div className="series-header">
        {info.coverImage && (
          <img src={info.coverImage} alt={info.name} className="series-cover" />
        )}
        <h2 className="series-title">{info.name}</h2>
        <span className="series-count">{info.count} 篇</span>
      </div>
      <ul className="series-posts">
        {posts.map(post => (
          <li key={post.id}>
            <Link to={`/blog/${post.id}`}>{post.title}</Link>
          </li>
        ))}
      </ul>
    </section>
  );
}
```
