## 2. `app/src/lib/markdown.ts` — 解析 `series:` frontmatter

在 `tagsMatch` 附近加一行:

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();
```

不给默认值 —— `series` 不存在就是 `undefined`,代表"不属于任何系列"。因为 `parseBlogMetadata` 是飞书和本地 md 共用的入口,这一处改动两条链路同时生效。

frontmatter 用法示例:

```yaml
---
title: "从 0 到 1:AI 转型的第一步"
series: AI 转型指南
category: AI
---
```

## 3. 新增 `app/src/content/series.ts` — 系列元数据注册表(单一真源)

```ts
/**
 * [OUTPUT]: 对外提供 seriesRegistry(系列名 -> 封面/简介)与 getSeriesCover
 * [POS]: 系列封面图是本地资源,与 feishu/static 两条文章数据链路解耦——
 *        文章 frontmatter 里的 series 只是关联键,封面图统一由本文件的本地路径提供,
 *        不重复写进每篇文章,避免同系列封面在多篇文章间漂移
 * [PROTOCOL]: 变更时更新此头部,然后检查 CLAUDE.md
 */
export interface SeriesMeta {
  name: string;
  cover: string;
  description?: string;
}

export const seriesRegistry: Record<string, SeriesMeta> = {
  'AI 转型指南': {
    name: 'AI 转型指南',
    cover: 'covers/series/ai-transformation.svg',
    description: '从 0 到 1 落地 AI 能力的系列文章',
  },
};

export function getSeriesCover(name: string): string {
  return seriesRegistry[name]?.cover ?? '';
}
```

封面图片实际放在 `app/src/content/covers/series/ai-transformation.svg`(和现有本地文章封面同一套目录习惯)。新增系列 = 在这个对象里加一条 + 放一张图,文章 frontmatter 里 `series` 名字对上即可,不用改本文件之外的东西。

## 4. `app/src/data/blogs.ts` — 导出 `resolveCover`,新增分组函数

先把已有的 `resolveCover` 加 `export`(供第 5 步系列封面复用同一套 BASE_URL 拼接逻辑):

```ts
export const resolveCover = (cover: string): string =>
  !cover || /^(https?:)?\/\//.test(cover) || cover.startsWith('/')
    ? cover
    : `${import.meta.env.BASE_URL}${cover}`;
```

在文件末尾(`clearCache` 之后)加:

```ts
import { getSeriesCover } from '@/content/series';

export interface SeriesGroup {
  name: string;
  cover: string;
  posts: BlogPost[];
}

/**
 * 按系列分组博客文章
 * 无 series 字段的文章不进入任何分组;分组按组内最新文章日期降序排列
 */
export async function getPostsGroupedBySeries(): Promise<SeriesGroup[]> {
  const posts = await getBlogPosts();
  const groups = new Map<string, BlogPost[]>();

  posts.forEach(post => {
    if (!post.series) return;
    if (!groups.has(post.series)) groups.set(post.series, []);
    groups.get(post.series)!.push(post);
  });

  return Array.from(groups.entries())
    .map(([name, seriesPosts]) => {
      const sorted = seriesPosts.sort((a, b) => b.date.localeCompare(a.date));
      const rawCover = getSeriesCover(name);
      return {
        name,
        cover: rawCover ? resolveCover(rawCover) : sorted[0].coverImage,
        posts: sorted,
      };
    })
    .sort((a, b) => b.posts[0].date.localeCompare(a.posts[0].date));
}
```

注意 `rawCover ? resolveCover(rawCover) : ...`:空字符串不能直接丢给 `resolveCover`,否则会拼出一个只有 `BASE_URL` 的错误路径。注册表里没登记封面时,退化为该系列最新一篇文章自己的封面,而不是空图或占位图——延续你现有代码"降级到真实数据、不用假占位"的原则。

## 5. 列表页分组展示

我没看到 `pages/Blog.tsx` 的源码,下面给一个独立组件 + 接入方式,导入路径按你实际的 `BlogCard`/组件目录调整即可。

新增 `app/src/components/blog/SeriesSection.tsx`:

```tsx
import type { SeriesGroup } from '@/data/blogs';

export function SeriesSection({ groups }: { groups: SeriesGroup[] }) {
  if (groups.length === 0) return null;

  return (
    <section className="mb-12">
      <h2 className="text-2xl font-bold mb-6">系列文章</h2>
      <div className="grid gap-6 md:grid-cols-2">
        {groups.map(group => (
          <div key={group.name} className="rounded-xl overflow-hidden border">
            <img src={group.cover} alt={group.name} className="w-full h-40 object-cover" />
            <div className="p-4">
              <h3 className="font-semibold text-lg">{group.name}</h3>
              <p className="text-sm text-gray-500 mb-2">共 {group.posts.length} 篇</p>
              <ul className="space-y-1">
                {group.posts.map(post => (
                  <li key={post.id}>
                    <a href={`/blog/${post.id}`} className="text-sm hover:underline">
                      {post.title}
                    </a>
                  </li>
                ))}
              </ul>
            </div>
          </div>
        ))}
      </div>
    </section>
  );
}
```

在 Blog 列表页里接入(在原有的分类/标签筛选逻辑之上加一段,不替换现有平铺列表):

```tsx
import { getPostsGroupedBySeries } from '@/data/blogs';
import { SeriesSection } from '@/components/blog/SeriesSection';

// 在页面组件里
const [seriesGroups, setSeriesGroups] = useState<SeriesGroup[]>([]);
useEffect(() => {
  getPostsGroupedBySeries().then(setSeriesGroups);
}, []);

// 渲染时,放在筛选控件之前
<SeriesSection groups={seriesGroups} />
```
