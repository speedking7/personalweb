# 系列文章功能实现方案

核心设计：`series` 只在文章 frontmatter 里存"系列名"（字符串），系列封面单独用一张配置表维护（名称 → 本地图片路径），避免同一系列的封面在每篇文章里重复写、后续改封面要改多处。分组逻辑放在 `data/blogs.ts`，因为它已经是飞书 + 本地两条数据链路汇合之后的统一出口——分组不关心文章来自哪个数据源。

## 1. `app/src/types/blog.ts` —— 新增字段和分组类型

```ts
export interface BlogPost {
  id: string;
  title: string;
  excerpt: string;
  content: string;
  coverImage: string;
  category: string;
  tags: string[];
  date: string;
  readTime: number;
  series?: string;
}

export interface BlogSeriesGroup {
  name: string;
  coverImage: string;
  posts: BlogPost[];
}
```

## 2. `app/src/lib/markdown.ts` —— 解析 frontmatter 里的 `series`

在 `categoryMatch` 附近加一行，和其他字段写法保持一致：

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();
```

`series` 不给默认值（不像 `category` 兜底成"未分类"），因为没写 `series` 就代表这篇文章不属于任何系列，语义不同，不能兜底。

同时按文件头部的 `[PROTOCOL]` 约定，把 `[OUTPUT]` 那行加一句："额外识别 `series` 字段（无默认值，不存在即表示不属于任何系列）"。这个函数是飞书文档和本地 md 共用的入口，这一处改完两条链路自动都支持 `series`，不需要再碰 `feishu.ts`。

## 3. `app/src/data/seriesCovers.ts` —— 新建，系列封面配置

```ts
/**
 * 系列封面配置：系列名 -> 本地封面相对路径（相对 public/ 目录）
 * 按名称与文章 frontmatter 的 series 字段对应；未在此登记的系列会拿到空封面
 */
export const seriesCovers: Record<string, string> = {
  'AI 转型指南': 'series-covers/ai-transformation.svg',
};
```

对应把封面图片放到 `app/public/series-covers/ai-transformation.svg`（和现有文章封面 `covers/x.svg` 同一套目录规则，走 `public/` 直出，无需 import）。

## 4. `app/src/data/blogs.ts` —— 新增分组函数

```ts
import { seriesCovers } from './seriesCovers';
import type { BlogPost, BlogSeriesGroup } from '@/types/blog';

/**
 * 按系列分组，只返回带 series 字段的文章
 */
export async function getPostsBySeries(): Promise<BlogSeriesGroup[]> {
  const posts = await getBlogPosts();
  const groups = new Map<string, BlogPost[]>();

  for (const post of posts) {
    if (!post.series) continue;
    const list = groups.get(post.series) ?? [];
    list.push(post);
    groups.set(post.series, list);
  }

  return Array.from(groups.entries()).map(([name, seriesPosts]) => ({
    name,
    coverImage: resolveCover(seriesCovers[name] ?? ''),
    posts: seriesPosts.sort((a, b) => b.date.localeCompare(a.date)),
  }));
}

/**
 * 不属于任何系列的文章，供列表页在分组区域下方继续展示
 */
export async function getUngroupedPosts(): Promise<BlogPost[]> {
  const posts = await getBlogPosts();
  return posts.filter(post => !post.series);
}
```

`resolveCover` 在文件里已经是私有函数（处理绝对 URL 直通、相对路径补 `BASE_URL`），系列封面复用它，保证和文章封面同一套路径规则，不用再写一遍判断逻辑。

分组是在 `getBlogPosts()` 拿到最终列表之后做的，所以不管当前是 `feishu`/`static`/`auto` 哪种模式，分组结果都一致，不需要碰 `feishuBlogClient`。

## 5. 博客列表页（`app/src/pages/Blog.tsx`，按你项目里实际文件名替换）

```tsx
import { useEffect, useState } from 'react';
import { getPostsBySeries, getUngroupedPosts } from '@/data/blogs';
import type { BlogSeriesGroup, BlogPost } from '@/types/blog';

function BlogList() {
  const [seriesGroups, setSeriesGroups] = useState<BlogSeriesGroup[]>([]);
  const [ungroupedPosts, setUngroupedPosts] = useState<BlogPost[]>([]);

  useEffect(() => {
    getPostsBySeries().then(setSeriesGroups);
    getUngroupedPosts().then(setUngroupedPosts);
  }, []);

  return (
    <>
      {seriesGroups.map(group => (
        <section key={group.name} className="series-group">
          <div className="series-header">
            {group.coverImage && (
              <img src={group.coverImage} alt={group.name} className="series-cover" />
            )}
            <h2>{group.name}</h2>
            <span>{group.posts.length} 篇</span>
          </div>
          <div className="series-posts">
            {group.posts.map(post => (
              <BlogCard key={post.id} post={post} />
            ))}
          </div>
        </section>
      ))}

      {ungroupedPosts.length > 0 && (
        <section className="ungrouped-posts">
          {ungroupedPosts.map(post => (
            <BlogCard key={post.id} post={post} />
          ))}
        </section>
      )}
    </>
  );
}
```

`BlogCard` 沿用你现有的文章卡片组件，这里假设已存在（原来渲染扁平列表用的那个）。如果现有列表页是按 `getBlogPosts()` 单一数组直接 `.map` 渲染的，就把那段替换成上面两块。

## 6. 文章 frontmatter 用法示例

```md
---
title: "为什么我们要做 AI 转型"
category: "AI"
series: "AI 转型指南"
tags: [AI, 转型]
date: "2026-08-01"
cover: "covers/ai-1.svg"
---
正文内容...
```

同一系列的多篇文章只要 `series` 字段写同名字符串即可自动归组，系列封面只在 `seriesCovers.ts` 里配一次。

## 边界情况

- 系列名没在 `seriesCovers.ts` 里登记时，`coverImage` 是空字符串，页面上用 `{group.coverImage && <img .../>}` 判断跳过渲染，不会出现 broken image。
- 飞书来源的文章如果 frontmatter 里也写了 `series`，会自动生效（前提是飞书文档同样过 `parseBlogMetadata` 解析，从贴出的头部注释看这是既定契约）。
