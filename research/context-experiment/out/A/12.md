关键设计决定:系列封面**不放进文章 frontmatter**,单独建注册表。因为文章可能来自飞书(无法引用本地文件路径),而封面要求"本地相对路径";单独一张表可以让飞书文章和本地文章共用同一套系列封面。

### 2. `app/src/lib/markdown.ts`

在 `tagsMatch` 块后面加一行解析,其余不变:

```ts
const tagsMatch = frontmatter.match(/tags:\s*\[([^\]]+)\]/);
if (tagsMatch) {
  metadata.tags = tagsMatch[1].split(',').map(tag => tag.trim().replace(/["']/g, ''));
}

const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();
```

不用改默认值兜底部分——`series` 是可选字段,未命中就保持 `undefined`,不需要像 `category`/`tags` 那样强制给默认值。

按该文件 `[PROTOCOL]` 约定,顺带更新头部注释的 `[OUTPUT]` 行:

```ts
/**
 * [INPUT]: 依赖 @/types/blog 的 BlogPost 契约
 * [OUTPUT]: 对外提供 parseBlogMetadata —— 把带 YAML frontmatter 的 markdown 解析为 BlogPost 字段，
 *           包含可选的 series 字段（未命中时不写入，不覆盖调用方默认值）
 * [POS]: lib/ 层的格式解析器，是飞书文档与本地 md 文件的共同入口。
 *        两个数据源必须共用它，否则元数据规则会各自漂移，同一篇文章在两条链路上解析出不同结果
 * [PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
 */
```

### 3. 新建 `app/src/data/series.ts`

```ts
/**
 * [INPUT]: 无外部依赖，纯静态注册表
 * [OUTPUT]: 对外提供 seriesCovers（系列名 -> 封面相对路径）与 DEFAULT_SERIES_COVER 兜底封面
 * [POS]: data/ 层的系列封面注册表，与 lib/markdown 解析出的 post.series 按名称精确匹配。
 *        封面刻意不放进文章 frontmatter：文章可能来自飞书（无法引用本地文件），
 *        系列封面却要求本地相对路径，所以单独维护一张表，飞书/本地文章共用
 * [PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
 */

// key 必须与文章 frontmatter 里的 series 值逐字符一致，否则该系列会退回默认封面
export const seriesCovers: Record<string, string> = {
  'AI 转型指南': 'covers/series/ai-transform.svg',
};

export const DEFAULT_SERIES_COVER = 'covers/series/default.svg';
```

图片本体放 `app/public/covers/series/ai-transform.svg`(和 `default.svg`)—— 沿用项目里博客封面已有的部署方式:`public/` 下的静态文件,运行时用 `BASE_URL` 拼相对路径访问,不是 `import` 进 JS 的模块,不会被打包处理。

### 4. `app/src/data/blogs.ts`

顶部加两个 import:

```ts
import { seriesCovers, DEFAULT_SERIES_COVER } from './series';
import type { BlogPost, SeriesGroup } from '@/types/blog';
```

在 `getPostsByTag` 之后、`searchPosts` 之前插入两个新函数,复用文件里已有的私有 `resolveCover`:

```ts
/**
 * 按系列分组博客
 * 只收录写了 series 字段的文章；组内按日期倒序，组间按各系列最新一篇的日期倒序
 */
export async function getSeriesGroups(): Promise<SeriesGroup[]> {
  const posts = await getBlogPosts();
  const groups = new Map<string, BlogPost[]>();

  posts.forEach(post => {
    if (!post.series) return;
    const list = groups.get(post.series) ?? [];
    list.push(post);
    groups.set(post.series, list);
  });

  return Array.from(groups.entries())
    .map(([name, seriesPosts]) => ({
      name,
      cover: resolveCover(seriesCovers[name] ?? DEFAULT_SERIES_COVER),
      posts: seriesPosts.sort((a, b) => b.date.localeCompare(a.date)),
    }))
    .sort((a, b) => b.posts[0].date.localeCompare(a.posts[0].date));
}

/**
 * 没有系列归属的文章，供列表页在系列分组之外单独展示
 */
export async function getUngroupedPosts(): Promise<BlogPost[]> {
  const posts = await getBlogPosts();
  return posts.filter(post => !post.series);
}
```

同时更新文件头部 `[OUTPUT]` 一行:

```ts
 * [OUTPUT]: 对外提供 getBlogPosts/getBlogPost 读取、getCategories/getTags 聚合、
 *           getPostsByCategory/getPostsByTag/searchPosts 筛选、
 *           getSeriesGroups/getUngroupedPosts 系列分组、
 *           setDataSourceMode 与 clearCache 控制
```

### 5. 列表页(你项目里对应 `pages/Blog.tsx` 之类的组件)

我这边没有该文件源码,按 `blogs.ts` 头部注释里写的调用关系(pages/Blog·BlogDetail·Home 消费这层)给出接入方式,字段名对齐即可:

```tsx
import { getSeriesGroups, getUngroupedPosts } from '@/data/blogs';
import type { SeriesGroup, BlogPost } from '@/types/blog';

const [seriesGroups, setSeriesGroups] = useState<SeriesGroup[]>([]);
const [ungroupedPosts, setUngroupedPosts] = useState<BlogPost[]>([]);

useEffect(() => {
  getSeriesGroups().then(setSeriesGroups);
  getUngroupedPosts().then(setUngroupedPosts);
}, []);

// 渲染
{seriesGroups.map(group => (
  <section key={group.name} className="series-group">
    <div className="series-header" style={{ backgroundImage: `url(${group.cover})` }}>
      <h2>{group.name}</h2>
      <span>{group.posts.length} 篇</span>
    </div>
    <div className="series-posts">
      {group.posts.map(post => <BlogCard key={post.id} post={post} />)}
    </div>
  </section>
))}

{ungroupedPosts.map(post => <BlogCard key={post.id} post={post} />)}
```

`BlogCard` 用你现有的文章卡片组件即可,这里不改它的 props。
