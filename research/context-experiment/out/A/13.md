基于现有代码结构(未见到列表页组件源码,该部分按现有 `getBlogPosts()` 调用模式给出可直接套用的模式代码)给出方案:

## 设计要点
系列封面**不**放进每篇文章的 frontmatter 重复填写——那样改一次封面要改 N 个文件,且容易出现同系列图片不一致(与本项目一贯"避免数据漂移"的原则相悖)。改为一个独立的系列注册表文件,单一数据源。frontmatter 里只需要 `series: 系列名`。

## 1. `app/src/types/blog.ts` — 加字段

```ts
export interface BlogPost {
  id: string;
  title: string;
  excerpt: string;
  content: string;
  coverImage: string;
  category: string;
  tags: string[];
  date: string;
  readTime: number;
  series?: string; // 不属于任何系列时不设置,不要给默认值
}

export interface BlogSeries {
  name: string;
  cover: string;
  posts: BlogPost[];
}
```

## 2. 新建 `app/src/content/series.ts` — 系列封面注册表

```ts
/**
 * 系列封面注册表：系列名 -> 封面图相对路径(相对 public/ 目录，写法与文章 cover 字段一致)
 * 新增系列文章时先在这里登记封面，无需在每篇 frontmatter 里重复填
 */
export const seriesCovers: Record<string, string> = {
  'AI 转型指南': 'series-covers/ai-transform.svg',
};
```

封面图片放到 `app/public/series-covers/ai-transform.svg`(与现有 `public/covers/*` 同级目录、同一套 BASE_URL 拼接逻辑)。

## 3. `app/src/lib/markdown.ts` — 解析 `series` 字段

在 `categoryMatch` 逻辑块后加:

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();
```

**不要**加默认值(不像 `category` 那样兜底 `'未分类'`)——否则所有文章都会被强行分进一个"系列"。

## 4. `app/src/data/blogs.ts` — 新增分组聚合函数

```ts
import { seriesCovers } from '@/content/series';
import type { BlogPost, BlogSeries } from '@/types/blog';

/**
 * 按系列分组博客文章。只包含带 series 字段的文章。
 * 系列内按 date 升序（阅读顺序），系列间按各自最新一篇的 date 降序
 */
export async function getPostsBySeries(): Promise<BlogSeries[]> {
  const posts = await getBlogPosts();
  const groups = new Map<string, BlogPost[]>();
  for (const post of posts) {
    if (!post.series) continue;
    const list = groups.get(post.series) ?? [];
    list.push(post);
    groups.set(post.series, list);
  }

  const series: BlogSeries[] = Array.from(groups.entries()).map(([name, seriesPosts]) => {
    const ordered = [...seriesPosts].sort((a, b) => a.date.localeCompare(b.date));
    const cover = seriesCovers[name];
    if (!cover) {
      console.warn(`系列 "${name}" 未在 series.ts 登记封面，回退到该系列首篇文章封面`);
    }
    return { name, cover: cover ? resolveCover(cover) : ordered[0].coverImage, posts: ordered };
  });

  return series.sort((a, b) =>
    b.posts[b.posts.length - 1].date.localeCompare(a.posts[a.posts.length - 1].date)
  );
}
```

`resolveCover` 已在文件内定义为模块级函数,直接复用,系列封面走和文章封面完全一致的相对路径/BASE_URL 解析规则。`staticBlogPosts` 的构造代码不用改——`series` 字段会随 `parseBlogMetadata` 的解构结果自动透传。

**需要核对一处我看不到源码的地方**:`lib/feishu.ts` 里构造 `BlogPost` 时如果对字段做了白名单过滤(而不是直接展开 `parseBlogMetadata` 的返回值),需要在那里同样加上 `series` 透传,否则飞书数据源的系列信息会丢失。

## 5. 新建 `app/src/components/blog/SeriesSection.tsx` — 分组展示组件

```tsx
import { Link } from 'react-router-dom';
import type { BlogSeries } from '@/types/blog';

export function SeriesSection({ series }: { series: BlogSeries[] }) {
  if (series.length === 0) return null;

  return (
    <section className="mb-10">
      <h2 className="text-xl font-semibold mb-4">系列文章</h2>
      <div className="flex gap-4 overflow-x-auto pb-2">
        {series.map(s => (
          <Link
            key={s.name}
            to={`/blog?series=${encodeURIComponent(s.name)}`}
            className="relative flex-shrink-0 w-64 h-36 rounded-lg overflow-hidden group"
          >
            <img src={s.cover} alt={s.name} className="w-full h-full object-cover transition-transform group-hover:scale-105" />
            <div className="absolute inset-0 bg-black/40 flex flex-col justify-end p-3">
              <span className="text-white font-medium">{s.name}</span>
              <span className="text-white/80 text-sm">{s.posts.length} 篇</span>
            </div>
          </Link>
        ))}
      </div>
    </section>
  );
}
```
(class 名按项目实际样式方案调整,这里假设是 Tailwind,与项目实际是否一致我未能确认。)

## 6. 接入列表页(在调用 `getBlogPosts()` 渲染卡片的那个页面组件里,通常是 `pages/Blog.tsx`)

```tsx
const [series, setSeries] = useState<BlogSeries[]>([]);
const [searchParams] = useSearchParams();
const seriesFilter = searchParams.get('series');

useEffect(() => {
  getPostsBySeries().then(setSeries);
}, []);

const displayedPosts = seriesFilter ? posts.filter(p => p.series === seriesFilter) : posts;
```

渲染时在文章网格上方插入 `<SeriesSection series={series} />`;点击某个系列卡片跳到 `/blog?series=系列名`,主列表按 `displayedPosts` 过滤,并给一个"返回全部文章"链接清除该 query 参数。
