# 系列文章功能实现方案

核心思路：`series` 只是文章 frontmatter 里的一个字符串字段（关联用），系列的封面/描述放在一个独立的注册表文件里维护（因为封面是"系列级"的元数据，不适合让每篇文章重复填一遍）。

## 改动文件清单

| 文件 | 改动 |
|---|---|
| `app/src/types/blog.ts` | `BlogPost` 增加 `series?` `seriesOrder?` |
| `app/src/lib/markdown.ts` | frontmatter 解析增加 `series` / `seriesOrder` |
| `app/src/lib/feishu.ts` | 透传 `series` / `seriesOrder` 字段 |
| `app/src/lib/utils.ts` | 抽出共用的 `resolveCover`（供系列封面复用） |
| `app/src/data/blogs.ts` | 改用共用的 `resolveCover`，删除本地重复定义 |
| `app/src/data/series.ts` **(新增)** | 系列注册表：名称 + 封面 + 描述 |
| `app/src/pages/Blog.tsx` | 列表页按系列分组展示 + 系列筛选 |
| `app/public/series-covers/*` **(新增图片)** | 系列封面图存放位置 |

## 1. `app/src/types/blog.ts`

```ts
export interface BlogPost {
  id: string;
  title: string;
  excerpt: string;
  content: string;
  coverImage: string;
  category: string;
  tags: string[];
  date: string;
  readTime: number;
  /** 系列名称，需与 data/series.ts 中登记的系列名完全一致 */
  series?: string;
  /** 系列内排序，越小越靠前；不填则按日期升序排列 */
  seriesOrder?: number;

```

## 2. `app/src/lib/markdown.ts`

在 `excerptMatch` 之后加两行解析（保持和其他字段一致的写法）：

```ts
    const excerptMatch = frontmatter.match(/excerpt:\s*["']?([^"'\n]+)["']?/);
    if (excerptMatch) metadata.excerpt = excerptMatch[1].trim();

    const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
    if (seriesMatch) metadata.series = seriesMatch[1].trim();

    const seriesOrderMatch = frontmatter.match(/seriesOrder:\s*(\d+)/);
    if (seriesOrderMatch) metadata.seriesOrder = parseInt(seriesOrderMatch[1]);

    // 移除 frontmatter，获取正文内容
    metadata.content = content.substring(frontmatterMatch[0].length).trim();
```

## 4. `app/src/lib/utils.ts`

把 `blogs.ts` 里原本私有的 `resolveCover` 提到这里，供系列封面复用（逻辑不变，纯移动）：

```ts
import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}

/** 相对路径补上部署 base（如 GitHub Pages 的 /personalweb/）；绝对 URL 与以 / 开头的路径原样返回 */
export const resolveCover = (cover: string): string =>
  !cover || /^(https?:)?\/\//.test(cover) || cover.startsWith('/')
    ? cover
    : `${import.meta.env.BASE_URL}${cover}`;
```

## 6. `app/src/data/series.ts`（新增）

```ts
/**
 * [INPUT]: 依赖 @/lib/utils 的 resolveCover 补全封面部署路径
 * [OUTPUT]: 对外提供 SeriesInfo 类型、seriesList 系列注册表、getSeriesInfo 查询
 * [POS]: data/ 层的系列元数据源，被 pages/Blog 消费用于分组展示。
 *        文章 frontmatter 里的 series 字段只是关联用的名称字符串，
 *        封面/简介等系列级元数据集中在此手工维护——同一系列的封面不该在每篇文章里重复填一遍
 * [PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
 */
import { resolveCover } from '@/lib/utils';

export interface SeriesInfo {
  /** 系列名称，必须与文章 frontmatter 中的 series 字段完全一致 */
  name: string;
  /** 封面图相对路径（相对于 public/），如 series-covers/ai-transform.svg */
  cover: string;
  description?: string;
}

const rawSeriesList: SeriesInfo[] = [
  // 新增系列在此登记，封面图放到 app/public/series-covers/ 下
  {
    name: 'AI 转型指南',
    cover: 'series-covers/ai-transform.svg',
    description: '从传统开发到 AI 时代的转型笔记',
  },
];

export const seriesList: SeriesInfo[] = rawSeriesList.map((s) => ({
  ...s,
  cover: resolveCover(s.cover),
}));

export function getSeriesInfo(name: string): SeriesInfo | undefined {
  return seriesList.find((s) => s.name === name);
}
```

## 7. `app/src/pages/Blog.tsx`

**import 增加：**

```ts
import { seriesList } from '@/data/series';
```

**state 增加（放在 `activeTag` 旁边）：**

```ts
const [activeSeries, setActiveSeries] = useState<string | null>(null);
```

**分组计算（放在 `archives` 计算之后）：**

```ts
// 只展示实际有文章的系列——注册表里挂了名但还没文章的系列不显示,
// 避免空系列卡片冒充成"内容已就绪"
const seriesGroups = seriesList
  .map((info) => ({
    info,
    posts: posts
      .filter((p) => p.series === info.name)
      .sort((a, b) =>
        a.seriesOrder != null && b.seriesOrder != null
          ? a.seriesOrder - b.seriesOrder
          : a.date.localeCompare(b.date)
      ),
  }))
  .filter((group) => group.posts.length > 0);
```

**筛选逻辑 `filteredPosts` 增加系列条件：**

```ts
const filteredPosts = posts.filter((post) => {
  const matchesCategory =
    activeCategory === '全部' || post.category === activeCategory;
  const matchesTag = !activeTag || post.tags.includes(activeTag);
  const matchesSeries = !activeSeries || post.series === activeSeries;
  const matchesSearch =
    !searchQuery ||
    post.title.toLowerCase().includes(searchQuery.toLowerCase()) ||
    post.excerpt.toLowerCase().includes(searchQuery.toLowerCase());
  return matchesCategory && matchesTag && matchesSeries && matchesSearch;
});
```

## 8. 封面图片位置

`resolveCover` 只是给相对路径拼 `BASE_URL` 前缀，实际文件要放进 Vite 的静态目录才能被访问到，即：

```
app/public/series-covers/ai-transform.svg
```

和现有文章封面（`covers/x.svg`）走的是同一套机制。

## 9. 文章里怎么用

```md
---
title: "AI 转型指南（一）：从写代码到写提示词"
series: "AI 转型指南"
seriesOrder: 1
category: "技术"
tags: [AI, 转型]
date: "2026-08-01"
---
```

`series` 必须和 `data/series.ts` 里登记的名称完全一致（字符串精确匹配，没做归一化/大小写容错）。不填 `series` 的文章行为不受任何影响，仍走原来的普通列表逻辑。

---

**范围说明**：以上只覆盖你要求的三点。文章详情页（`BlogDetail.tsx`）目前不含"本系列其它文章"导航，如果需要可以后续单独加，用的是同一个 `seriesGroups` 计算逻辑，改动量很小，但不在本次方案内。
