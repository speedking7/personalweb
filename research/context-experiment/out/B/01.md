## 实现方案

系列功能拆成 4 处改动：类型 → frontmatter 解析 → 系列聚合器（新文件）→ 列表页展示。系列不是独立实体，而是从 `BlogPost.series` 字段实时归纳出的分组，新增系列不用改代码；只有要自定义封面图时才需要在配置里补一条——没配置封面的系列不借用别的图片顶替，页面上显式留白，这是延续这个项目已有的"不用假数据冒充"的做法。

---

### 1. `app/src/types/blog.ts` —— 加字段

```ts
export interface BlogPost {
  id: string;
  title: string;
  excerpt: string;
  content: string;
  coverImage: string;
  category: string;
  tags: string[];
  series?: string;   // 新增：所属系列名，不填则不参与系列分组
  date: string;
  readTime: number;
}
```

### 2. `app/src/lib/markdown.ts` —— 解析 `series:` frontmatter

在 `categoryMatch` 那块下面加一段（两个数据源共用这个解析器，改一处两边都生效）：

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();
```

### 3. `app/src/lib/feishu.ts` —— 飞书链路补传 series 字段

`fetchBlogPosts()` 里 `posts.push({...})` 目前是显式白名单字段，`metadata.series` 解析出来了但没被带上，飞书文章的系列会静默丢失。补一行：

```ts
posts.push({
  id: metadata.id!,
  title: metadata.title || node.title,
  excerpt: metadata.excerpt || '',
  content: metadata.content || content,
  coverImage: metadata.coverImage || this.getDefaultCover(metadata.category),
  category: metadata.category || '未分类',
  tags: metadata.tags || [],
  series: metadata.series,          // 新增
  date: metadata.date || new Date().toISOString().split('T')[0],
  readTime: metadata.readTime || 5,
});
```

### 4. `app/src/data/blogs.ts` —— 导出 `resolveCover` 供复用

系列封面和文章封面要用同一套「相对路径 + BASE_URL 前缀」解析规则（GitHub Pages 部署有 `/personalweb/` 前缀），直接复用现成函数，只加一个 `export`：

```ts
export const resolveCover = (cover: string): string =>
  !cover || /^(https?:)?\/\//.test(cover) || cover.startsWith('/')
    ? cover
    : `${import.meta.env.BASE_URL}${cover}`;
```

### 5. 新建 `app/src/data/series.ts` —— 系列聚合器

```ts
/**
 * [INPUT]: 依赖 @/data/blogs 的 getBlogPosts 取文章列表与 resolveCover 处理封面路径，
 *           依赖 @/types/blog 的 BlogPost 契约
 * [OUTPUT]: 对外提供 seriesConfig 系列封面配置、SeriesGroup 类型、getSeriesList 分组聚合
 * [POS]: data/ 层的系列文章聚合器，被 pages/Blog 消费。系列不是独立实体，而是从
 *        BlogPost.series 字段实时归纳出的分组视图；只有要自定义封面图时才需要在
 *        seriesConfig 里补一条。没配置封面的系列不借用文章封面顶替，宁可页面上
 *        显式留白，也不用可能不准确的图片冒充
 * [PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
 */
import { getBlogPosts, resolveCover } from './blogs';
import type { BlogPost } from '@/types/blog';

export interface SeriesInfo {
  /** 相对路径，如 series-covers/ai.svg；实际文件放在 app/public/series-covers/ 下 */
  cover: string;
  description?: string;
}

// 系列名需与文章 frontmatter 里的 series 完全一致，才能匹配到封面
export const seriesConfig: Record<string, SeriesInfo> = {
  'AI 转型指南': {
    cover: 'series-covers/ai-transformation.svg',
    description: '从工具使用到组织变革的系列笔记',
  },
};

export interface SeriesGroup {
  name: string;
  cover: string;
  description?: string;
  posts: BlogPost[];
}

/**
 * 按 series 分组；没有 series 字段的文章不参与分组。
 * 组内按日期升序（阅读顺序），组间按最新一篇日期降序。
 */
export async function getSeriesList(): Promise<SeriesGroup[]> {
  const posts = await getBlogPosts();
  const groups = new Map<string, BlogPost[]>();

  for (const post of posts) {
    if (!post.series) continue;
    const list = groups.get(post.series) ?? [];
    list.push(post);
    groups.set(post.series, list);
  }

  return Array.from(groups.entries())
    .map(([name, groupPosts]) => {
      const sorted = [...groupPosts].sort((a, b) => a.date.localeCompare(b.date));
      const info = seriesConfig[name];
      return {
        name,
        cover: info ? resolveCover(info.cover) : '',
        description: info?.description,
        posts: sorted,
      };
    })
    .sort((a, b) =>
      b.posts[b.posts.length - 1].date.localeCompare(a.posts[a.posts.length - 1].date)
    );
}
```

再建 `app/public/series-covers/` 目录，把系列封面图放进去，`seriesConfig` 里填相对该目录的文件名即可（跟站内文章封面 `covers/x.svg` 是同一套约定）。

### 6. `app/src/pages/Blog.tsx` —— 列表页分组展示

**导入 + 状态**

```tsx
import { getSeriesList, type SeriesGroup } from '@/data/series';

const [seriesList, setSeriesList] = useState<SeriesGroup[]>([]);
const [activeSeries, setActiveSeries] = useState<string | null>(null);
```

**加载**（并入现有 `Promise.all`）

```tsx
const [loadedPosts, loadedCategories, loadedTags, loadedSeries] = await Promise.all([
  getBlogPosts(),
  getCategories(),
  getTags(),
  getSeriesList(),
]);
// ...
setSeriesList(loadedSeries);
```

**筛选逻辑**（在 `filteredPosts` 的 filter 里加一条，并在系列筛选时切换为阅读顺序）

```tsx
const filteredPosts = posts.filter((post) => {
  const matchesCategory = activeCategory === '全部' || post.category === activeCategory;
  const matchesTag = !activeTag || post.tags.includes(activeTag);
  const matchesSeries = !activeSeries || post.series === activeSeries;
  const matchesSearch =
    !searchQuery ||
    post.title.toLowerCase().includes(searchQuery.toLowerCase()) ||
    post.excerpt.toLowerCase().includes(searchQuery.toLowerCase());
  return matchesCategory && matchesTag && matchesSeries && matchesSearch;
});

// 选中系列时按阅读顺序（日期升序）展示，而不是全站默认的最新在前
const displayPosts = activeSeries
  ? [...filteredPosts].sort((a, b) => a.date.localeCompare(b.date))
  : filteredPosts;
```

把下方 `filteredPosts.map(...)` 改成 `displayPosts.map(...)`。

**系列卡片展示**（放在 Header 和 `grid lg:grid-cols-3` 之间，横向滚动、带封面图）

```tsx
{seriesList.length > 0 && (
  <div className="mb-6 flex gap-4 overflow-x-auto pb-2">
    {seriesList.map((series) => (
      <button
        key={series.name}
        onClick={() => setActiveSeries(activeSeries === series.name ? null : series.name)}
        className={`shrink-0 w-56 text-left rounded-xl overflow-hidden shadow-sm transition-all ${
          activeSeries === series.name ? 'ring-2 ring-[#1a1a1a]' : ''
        }`}
      >
        {series.cover ? (
          <div className="aspect-video bg-[#e5e5e5]">
            <img src={series.cover} alt={series.name} className="w-full h-full object-cover" />
          </div>
        ) : (
          <div className="aspect-video bg-[#e5e5e5] flex items-center justify-center text-[#9ca3af] text-sm px-3 text-center">
            {series.name}
          </div>
        )}
        <div className="p-3 bg-white">
          <p className="font-medium text-[#1a1a1a] text-sm truncate">{series.name}</p>
          <p className="text-[#9ca3af] text-xs mt-0.5">{series.posts.length} 篇</p>
        </div>
      </button>
    ))}
  </div>
)}

{activeSeries && (
  <div className="flex items-center justify-between mb-4 px-1">
    <span className="text-sm text-[#6b6b6b]">
      正在查看系列：<span className="font-medium text-[#1a1a1a]">{activeSeries}</span>
    </span>
    <button
      onClick={() => setActiveSeries(null)}
      className="text-sm text-[#9ca3af] hover:text-[#1a1a1a]"
    >
      清除
    </button>
  </div>
)}
```

（可选）每篇文章卡片的 meta 行加一个系列徽标，方便从单篇文章反向感知归属：
```tsx
{post.series && (
  <span className="px-2 py-1 bg-[#f0f0f0] text-[#4a4a4a] text-xs font-medium rounded-full">
    系列·{post.series}
  </span>
)}
```

### 使用方式

在 `src/content/posts/*.md` 或飞书文档的 frontmatter 里加一行：

```
---
title: "从 Prompt 到工作流"
series: AI 转型指南
category: 技术
...
---
```

`series` 名字要和 `app/src/data/series.ts` 里 `seriesConfig` 的 key 完全一致才会命中封面；不配置也能正常分组，只是卡片上没有图、只显示系列名占位。
