## 实现方案

系列文章的核心设计：**系列归属由文章 frontmatter 的 `series` 字段决定，系列封面由独立的注册表维护**（不塞进每篇文章的 frontmatter，避免同系列文章重复填同一张封面、且互相可能填出不一致的值)。分组是纯函数、基于已加载的文章列表计算，不做二次请求。

涉及 6 个文件，1 个新增目录：

### 1. `app/src/types/blog.ts` —— 加字段


### 2. `app/src/lib/markdown.ts` —— frontmatter 解析 `series`

在 `categoryMatch` 解析块之后加一行同款解析（与 `category`/`date` 写法保持一致）：

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();
```

这样本地文章和飞书文档共用同一个解析器，两条链路自动同步支持 `series` 字段。

### 3. `app/src/lib/feishu.ts` —— 透传 `series`

### 4. 新增目录 `app/src/content/series-covers/`

放系列封面图片，例如 `ai-transformation.jpg`。用 ES `import` 而不是字符串路径引用——这样 Vite 会自动处理构建产物的哈希与 base path（`/personalweb/` 前缀），不需要像文章封面那样额外写 `resolveCover`。

### 5. 新建 `app/src/data/series.ts` —— 系列注册表

```ts
/**
 * [INPUT]: 无外部依赖，import 静态导入 content/series-covers/ 下的封面图
 * [OUTPUT]: 对外提供 Series 类型、seriesList 系列元数据、getSeriesInfo 查询
 * [POS]: data/ 层的系列元数据源，被 data/blogs 的 groupPostsBySeries 消费。
 *        封面与文章 frontmatter 解耦：一个系列的封面只需在此登记一次，
 *        新增该系列文章时无需重复填封面路径。frontmatter 里出现但未在此登记的
 *        系列名依然会被正常分组，只是卡片没有封面图——不阻塞使用
 * [PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
 */
import aiTransformationCover from '../content/series-covers/ai-transformation.jpg';

export interface Series {
  name: string;
  cover: string;
  description?: string;
}

export const seriesList: Series[] = [
  {
    name: 'AI 转型指南',
    cover: aiTransformationCover,
    description: '从零开始的 AI 转型实践笔记',
  },
];

const seriesByName = new Map(seriesList.map((s) => [s.name, s]));

export function getSeriesInfo(name: string): Series | undefined {
  return seriesByName.get(name);
}
```

新增系列时只需在 `seriesList` 里加一项 + 把图放进 `content/series-covers/`。

### 6. `app/src/data/blogs.ts` —— 加分组函数

顶部加 import，文件末尾（`clearCache` 之后）加导出：

```ts
import { getSeriesInfo } from '@/data/series';

export interface SeriesGroup {
  name: string;
  cover?: string;
  description?: string;
  posts: BlogPost[];
}

/**
 * 按 frontmatter 的 series 字段对已加载的文章分组，纯函数、不发请求。
 * 系列内按日期升序（复现阅读顺序），系列间按最新一篇日期降序。
 */
export function groupPostsBySeries(posts: BlogPost[]): SeriesGroup[] {
  const groups = new Map<string, BlogPost[]>();

  posts.forEach((post) => {
    if (!post.series) return;
    const list = groups.get(post.series) ?? [];
    list.push(post);
    groups.set(post.series, list);
  });

  return Array.from(groups.entries())
    .map(([name, seriesPosts]) => {
      const sorted = [...seriesPosts].sort((a, b) => a.date.localeCompare(b.date));
      const info = getSeriesInfo(name);
      return { name, cover: info?.cover, description: info?.description, posts: sorted };
    })
    .sort((a, b) => {
      const latestA = a.posts[a.posts.length - 1]?.date ?? '';
      const latestB = b.posts[b.posts.length - 1]?.date ?? '';
      return latestB.localeCompare(latestA);
    });
}
```

### 使用方式

给文章 frontmatter 加一行即可归入系列：

```md
---
title: "从需求分析开始"
category: "技术"
tags: [AI, 转型]
date: "2026-01-10"
series: "AI 转型指南"
---
```

系列名字符串必须在多篇文章间完全一致（区分大小写/空格），这是纯字符串匹配分组，没有 slug 层。如果后续系列多了容易打错字导致分不到一组，可以再考虑加一层 slug 校验，但目前 3 条需求没要求，先不做这个提前抽象。
