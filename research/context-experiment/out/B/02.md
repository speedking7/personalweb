## 设计思路

三个需求分层实现:
- **数据层**:`series` 是文章 frontmatter 里的普通字符串字段,和 `category` 同级解析;但封面图没法从文章反推,必须单独配一张"系列名 → 封面"的映射表。
- **聚合层**:新增 `data/series.ts`,按 `series` 字段把文章分组、按系列内文章的日期排出阅读顺序、决定封面(配置优先,没配就退到系列第一篇文章的封面,不用假占位图)。
- **展示层**:`Blog.tsx` 顶部加一排系列卡片,点击后用 URL 的 `?series=` 查询参数过滤列表(HashRouter 下 `useSearchParams` 照常可用),列表按系列内顺序显示"第 N 篇"。

有一个容易漏掉的坑:飞书数据源(`lib/feishu.ts`)在组装 `BlogPost` 时是逐字段手写的,新增字段必须同步过去,否则本地文章能分组、飞书文章却分不了组。

## 2. `lib/markdown.ts`

在 `frontmatterMatch` 分支里,紧挨着 `categoryMatch` 加一段:

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();
```

不给默认值——`category` 缺省会填 `'未分类'`,但 `series` 缺省应该保持 `undefined`,否则所有没写系列的文章会被误归进一个假的"未分类系列"。

## 4. `lib/assets.ts`(新建)

从 `data/blogs.ts` 里现有的 `resolveCover` 提出来,改成通用工具,后面系列封面也要用同一套规则:

```ts
/**
 * [INPUT]: 无外部依赖
 * [OUTPUT]: 对外提供 resolveAssetPath —— 给本地相对路径补上部署 base 前缀
 * [POS]: lib/ 层的路径工具,被 data/blogs.ts(文章封面)与 data/series.ts(系列封面)共用。
 *        绝对 URL 与以 / 开头的路径原样返回:飞书文章的封面是完整 URL,不能被前缀污染
 * [PROTOCOL]: 变更时更新此头部,然后检查 CLAUDE.md
 */
export const resolveAssetPath = (path: string): string =>
  !path || /^(https?:)?\/\//.test(path) || path.startsWith('/')
    ? path
    : `${import.meta.env.BASE_URL}${path}`;
```

## 5. `data/series.ts`(新建)

```ts
/**
 * [INPUT]: 依赖 @/lib/assets 的 resolveAssetPath 补全本地封面路径,@/types/blog 的 BlogPost 契约
 * [OUTPUT]: 对外提供 seriesMeta 配置表、SeriesGroup 类型、buildSeriesGroups 分组函数
 * [POS]: data/ 层的系列聚合器,被 data/blogs.ts 的 getSeriesGroups 调用,再供 pages/Blog 消费。
 *        文章 frontmatter 的 series 只是个名字字符串,封面图无法从文章反推,必须单独配置——
 *        seriesMeta 是唯一配置位置。未配置封面的系列,用该系列内最早一篇文章的封面兜底,
 *        而非占位图,避免"看起来配好了、实际是假图"
 * [PROTOCOL]: 变更时更新此头部,然后检查 CLAUDE.md
 */
import { resolveAssetPath } from '@/lib/assets';
import type { BlogPost } from '@/types/blog';

export interface SeriesMeta {
  cover: string;
  description?: string;
}

export interface SeriesGroup {
  name: string;
  cover: string;
  description?: string;
  posts: BlogPost[];
}

// 系列名 -> 封面配置。新增系列在此补一行,name 必须与文章 frontmatter 里的
// series 字段完全一致(含空格),否则文章不会被归入该系列。
// 封面图放在 src/content/covers/series/ 下,用相对路径引用。
export const seriesMeta: Record<string, SeriesMeta> = {
  'AI 转型指南': {
    cover: 'covers/series/ai-transform.svg',
    description: '从恐惧到拥抱,记录转型路上的每一步',
  },
};

/** 按 frontmatter 的 series 字段分组;没写 series 的文章不进入任何分组 */
export function buildSeriesGroups(posts: BlogPost[]): SeriesGroup[] {
  const groups = new Map<string, BlogPost[]>();

  for (const post of posts) {
    if (!post.series) continue;
    const list = groups.get(post.series) ?? [];
    list.push(post);
    groups.set(post.series, list);
  }

  return Array.from(groups.entries())
    .map(([name, groupPosts]) => {
      // 系列内按日期升序:第一篇排在前面,符合"按顺序阅读"的直觉
      const sorted = [...groupPosts].sort((a, b) => a.date.localeCompare(b.date));
      const meta = seriesMeta[name];
      return {
        name,
        cover: meta?.cover ? resolveAssetPath(meta.cover) : sorted[0].coverImage,
        description: meta?.description,
        posts: sorted,
      };
    })
    // 系列排序:以系列内最新一篇文章的日期降序,最近更新的系列排前面
    .sort((a, b) => {
      const latestA = a.posts[a.posts.length - 1].date;
      const latestB = b.posts[b.posts.length - 1].date;
      return latestB.localeCompare(latestA);
    });
}
```

## 6. `data/blogs.ts`

头部改用共享工具,删掉本地 `resolveCover`,改用 `resolveAssetPath`:

```ts
import { resolveAssetPath } from '@/lib/assets';
import { buildSeriesGroups, type SeriesGroup } from './series';
export type { SeriesGroup };

// ...原来的 resolveCover 函数整块删除...

const staticBlogPosts: BlogPost[] = Object.entries(localPostModules)
  .map(([path, raw]) => {
    const slug = path.split('/').pop()!.replace(/\.md$/, '');
    const post = { title: slug, excerpt: '', coverImage: '', ...parseBlogMetadata(raw, slug) } as BlogPost;
    return { ...post, coverImage: resolveAssetPath(post.coverImage) };   // 改这一处
  })
  .sort((a, b) => b.date.localeCompare(a.date));
```

文件末尾(`clearCache` 附近)新增:

```ts
/**
 * 获取系列分组
 * 复用 getBlogPosts 的降级结果,因此自动继承 feishu/static/auto 的同一降级策略
 */
export async function getSeriesGroups(): Promise<SeriesGroup[]> {
  const posts = await getBlogPosts();
  return buildSeriesGroups(posts);
}
```

## 使用方式

文章 frontmatter 加一行 `series`:

```md
---
title: "AI 转型指南(一):从恐惧到拥抱"
category: "技术"
series: "AI 转型指南"
cover: "covers/ai-1.svg"
date: "2026-01-10"
---
```

系列封面放到 `app/src/content/covers/series/` 下,在 `data/series.ts` 的 `seriesMeta` 里配一行:

```ts
'AI 转型指南': { cover: 'covers/series/ai-transform.svg', description: '...' },
```

不配的话会自动用该系列第一篇文章的封面兜底,不会出现空白或假占位图。
