## 实现方案

系列封面用集中配置管理(而非塞进每篇文章的 frontmatter)——一个系列只有一张封面，如果让每篇文章各自声明,同系列文章之间迟早会打架。这也符合项目里 `data/photos.ts`、`config/giscus.ts` 的既有模式:内容型元数据用专门的 data 文件维护单一数据源。

### 1. `app/src/types/blog.ts` — 加字段

```ts
export interface BlogPost {
  id: string;
  title: string;
  excerpt: string;
  content: string;
  coverImage: string;
  category: string;
  tags: string[];
  date: string;
  readTime: number;
  series?: string;   // 新增：所属系列名，无系列则不设置
}
```

### 2. `app/src/lib/markdown.ts` — 解析 frontmatter 的 `series` 字段

在 `parseBlogMetadata` 里，紧挨着 `categoryMatch` 之后加:

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();
```

这个函数同时被本地 md 和飞书文档共用，改一处两条数据源都生效。

### 3. `app/src/lib/feishu.ts` — 补上字段透传

`fetchBlogPosts()` 里手工拼 `posts.push({...})` 时漏了 `series`（其他字段都是手动映射，不是整体 spread），要显式加一行：

```ts
posts.push({
  id: metadata.id!,
  title: metadata.title || node.title,
  excerpt: metadata.excerpt || '',
  content: metadata.content || content,
  coverImage: metadata.coverImage || this.getDefaultCover(metadata.category),
  category: metadata.category || '未分类',
  tags: metadata.tags || [],
  date: metadata.date || new Date().toISOString().split('T')[0],
  readTime: metadata.readTime || 5,
  series: metadata.series,   // 新增
});
```

### 4. `app/src/data/series.ts` — 新建，系列封面配置

```ts
/**
 * [INPUT]: 依赖 vite 的 import.meta.env.BASE_URL 计算部署前缀
 * [OUTPUT]: 对外提供 seriesCovers 映射与 getSeriesCover 查询函数
 * [POS]: data/ 层的系列元数据，被 data/blogs 的 getSeriesGroups 消费。
 *        系列封面集中维护于此，不写进单篇文章 frontmatter——
 *        一个系列只有一张封面，分散声明会导致同系列文章互相冲突
 * [PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
 */

// 图片放在 public/series-covers/ 下，用相对路径引用；构建时自动补 BASE_URL 前缀
export const seriesCovers: Record<string, string> = {
  'AI 转型指南': 'series-covers/ai-transformation.svg',
};

const resolveCover = (cover: string): string =>
  !cover || /^(https?:)?\/\//.test(cover) || cover.startsWith('/')
    ? cover
    : `${import.meta.env.BASE_URL}${cover}`;

/** 未登记封面的系列返回空字符串，UI 侧据此决定占位样式，不假装有图 */
export function getSeriesCover(series: string): string {
  const cover = seriesCovers[series];
  return cover ? resolveCover(cover) : '';
}
```

图片实体放到 `app/public/series-covers/xxx.svg`（与现有 `covers/` 封面同级目录，走 Vite 的 public 静态托管，`resolveCover` 的前缀补齐逻辑与文章封面完全一致）。

### 5. `app/src/data/blogs.ts` — 新增分组函数

引入 `getSeriesCover`，新增类型和函数：

```ts
import { getSeriesCover } from '@/data/series';

export interface SeriesGroup {
  name: string;
  cover: string;
  posts: BlogPost[];
}

/**
 * 按系列分组文章，用于博客列表页的系列聚合展示。
 * 无 series 字段的文章不进入任何分组。
 */
export async function getSeriesGroups(): Promise<SeriesGroup[]> {
  const posts = await getBlogPosts();
  const groups = new Map<string, BlogPost[]>();

  posts.forEach((post) => {
    if (!post.series) return;
    const list = groups.get(post.series) ?? [];
    list.push(post);
    groups.set(post.series, list);
  });

  return Array.from(groups.entries()).map(([name, seriesPosts]) => ({
    name,
    cover: getSeriesCover(name),
    // 系列内按时间正序，符合从头读到尾的阅读顺序（列表页主流是倒序，这里刻意反过来）
    posts: seriesPosts.sort((a, b) => a.date.localeCompare(b.date)),
  }));
}
```

（`OUTPUT` 头部注释也要补一句 `getSeriesGroups 系列分组`，跟其他文件一样走 PROTOCOL。）

### 6. `app/src/pages/Blog.tsx` — 列表页渲染分组

```tsx
import { getBlogPosts, getCategories, getTags, getSeriesGroups, type BlogPost, type SeriesGroup } from '@/data/blogs';

// ...在组件内新增 state
const [seriesGroups, setSeriesGroups] = useState<SeriesGroup[]>([]);

// ...loadBlogData 里一并拉取
const [loadedPosts, loadedCategories, loadedTags, loadedSeries] = await Promise.all([
  getBlogPosts(),
  getCategories(),
  getTags(),
  getSeriesGroups(),
]);
setPosts(loadedPosts);
setCategories(loadedCategories);
setTags(loadedTags);
setSeriesGroups(loadedSeries);
```

在 Header 和 `grid lg:grid-cols-3` 主体之间插入系列区块（独立于分类/标签筛选，是另一维度的组织方式）：

```tsx
{!loading && !error && seriesGroups.length > 0 && (
  <div className="mb-10">
    <h2 className="text-xl font-medium text-[#1a1a1a] mb-4">系列专栏</h2>
    <div className="grid sm:grid-cols-2 lg:grid-cols-3 gap-4">
      {seriesGroups.map((group) => (
        <div key={group.name} className="bg-white rounded-xl overflow-hidden shadow-sm">
          {group.cover && (
            <div className="aspect-video overflow-hidden">
              <img
                src={group.cover}
                alt={group.name}
                className="w-full h-full object-cover"
              />
            </div>
          )}
          <div className="p-5">
            <h3 className="font-medium text-[#1a1a1a] mb-1">{group.name}</h3>
            <p className="text-[#9ca3af] text-sm mb-3">共 {group.posts.length} 篇</p>
            <ul className="space-y-1">
              {group.posts.map((post) => (
                <li key={post.id}>
                  <Link
                    to={`/blog/${post.id}`}
                    className="text-sm text-[#6b6b6b] hover:text-[#1a1a1a] transition-colors"
                  >
                    {post.title}
                  </Link>
                </li>
              ))}
            </ul>
          </div>
        </div>
      ))}
    </div>
  </div>
)}
```

### 7. 文章 frontmatter 用法示例

```markdown
---
title: "从传统开发到 AI 辅助开发"
category: "技术"
series: "AI 转型指南"
date: "2026-01-10"
---
```

系列名字符串要跟 `series.ts` 里的 key 完全一致（这是唯一的关联点，纯字符串匹配，无需额外 slug）。
