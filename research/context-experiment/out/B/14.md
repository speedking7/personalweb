## 总体思路

系列信息完全从文章 frontmatter 派生（不新增单独的注册表文件），这样系列的存在、包含哪些文章、显示顺序都由内容本身决定，不会出现「系列信息与实际文章脱节」的问题——这跟你现有 `getCategories`/`getTags` 的设计哲学是一致的。系列封面也走同样的路子：哪篇文章先声明了 `seriesCover`，就用哪篇的。

涉及 5 个文件的改动 + 1 个新增静态资源目录。

## 2. `app/src/lib/markdown.ts` —— 解析 frontmatter 新字段

在现有 `categoryMatch` 解析之后插入：

```ts
const seriesMatch = frontmatter.match(/series:\s*["']?([^"'\n]+)["']?/);
if (seriesMatch) metadata.series = seriesMatch[1].trim();

const seriesCoverMatch = frontmatter.match(/seriesCover:\s*["']?([^"'\n]+)["']?/);
if (seriesCoverMatch) metadata.seriesCover = seriesCoverMatch[1].trim();
```

不设默认值——没有 `series` 就是独立文章，`undefined` 是合法状态，不需要兜底成空字符串。

## 4. `app/src/data/blogs.ts` —— 本地文章封面路径解析 + 分组聚合函数

**(a)** `staticBlogPosts` 构建时，`seriesCover` 跟 `coverImage` 一样需要过 `resolveCover`（补部署 base，否则本地能看、GitHub Pages 上 404）：

```ts
const staticBlogPosts: BlogPost[] = Object.entries(localPostModules)
  .map(([path, raw]) => {
    const slug = path.split('/').pop()!.replace(/\.md$/, '');
    const post = { title: slug, excerpt: '', coverImage: '', ...parseBlogMetadata(raw, slug) } as BlogPost;
    return {
      ...post,
      coverImage: resolveCover(post.coverImage),
      seriesCover: post.seriesCover ? resolveCover(post.seriesCover) : undefined,
    };
  })
  .sort((a, b) => b.date.localeCompare(a.date));
```

**(b)** 文件末尾新增分组聚合函数（放在 `clearCache` 附近即可）：

```ts
export interface SeriesGroup {
  name: string;
  cover: string;
  posts: BlogPost[];
}

/**
 * 按 series 字段分组。封面取组内第一篇带 seriesCover 的文章——
 * 系列封面来自内容本身，不用另一份需要手动维护、容易和实际系列脱节的注册表。
 * 组内按日期升序：系列文章应从第一篇开始读。
 */
export function groupPostsBySeries(posts: BlogPost[]): SeriesGroup[] {
  const map = new Map<string, BlogPost[]>();
  for (const post of posts) {
    if (!post.series) continue;
    const list = map.get(post.series) ?? [];
    list.push(post);
    map.set(post.series, list);
  }

  return Array.from(map.entries()).map(([name, seriesPosts]) => {
    const sorted = [...seriesPosts].sort((a, b) => a.date.localeCompare(b.date));
    return {
      name,
      cover: sorted.find((p) => p.seriesCover)?.seriesCover || '',
      posts: sorted,
    };
  });
}
```

**(a)** import 补充：

**(b)** 新增状态（跟 `activeTag` 放一起）：

```ts
const [activeSeries, setActiveSeries] = useState<string | null>(null);
```

**(c)** 在 `archives` 计算之后，加分组计算：

```ts
const seriesGroups = groupPostsBySeries(posts);
```

**(d)** 改造 `filteredPosts`，加入系列过滤，并在系列筛选下按升序展示：

```ts
const filteredPosts = posts
  .filter((post) => {
    const matchesCategory =
      activeCategory === '全部' || post.category === activeCategory;
    const matchesTag = !activeTag || post.tags.includes(activeTag);
    const matchesSeries = !activeSeries || post.series === activeSeries;
    const matchesSearch =
      !searchQuery ||
      post.title.toLowerCase().includes(searchQuery.toLowerCase()) ||
      post.excerpt.toLowerCase().includes(searchQuery.toLowerCase());
    return matchesCategory && matchesTag && matchesSeries && matchesSearch;
  })
  .sort((a, b) => (activeSeries ? a.date.localeCompare(b.date) : 0));
```

**(e)** 在 Header（`<h1>博客文章</h1>` 那块）之后、"Search & Filter" 卡片之前，插入系列专栏区块：

```tsx
{seriesGroups.length > 0 && (

    <h2 className="text-lg font-medium text-[#1a1a1a] mb-3">系列专栏</h2>

      {seriesGroups.map((group) => (
        <button
          key={group.name}
          onClick={() =>
            setActiveSeries(activeSeries === group.name ? null : group.name)
          }
          className={`group flex items-center gap-4 rounded-xl overflow-hidden shadow-sm text-left transition-all bg-white ${
            activeSeries === group.name ? 'ring-2 ring-[#1a1a1a]' : 'hover:shadow-md'

        >
          {group.cover ? (
            <img
              src={group.cover}
              alt={group.name}
              className="w-24 h-24 object-cover shrink-0"
            />
          ) : (
            <div className="w-24 h-24 bg-[#f0f0f0] shrink-0" />
          )}
          <div className="py-3 pr-4">

            <p className="text-[#9ca3af] text-sm">{group.posts.length} 篇</p>

```

## 7. 文章 frontmatter 写法示例

系列内每篇文章都写同一个 `series` 值，`seriesCover` 至少一篇写上（推荐系列第一篇写，或每篇都写保持一致）：

```md
---
title: "AI 转型指南（一）：认知重建"
category: "技术"
series: "AI 转型指南"
seriesCover: "series-covers/ai-transformation.svg"
tags: [AI, 转型]
date: "2026-01-10"
readTime: 8
---
```
